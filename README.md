# Тестирование API коллекцией Postman

Коллекция запросов для проверки авторизации, баланса пользователя,
тем публикаций и документов ScanDoc.

## Что проверяется

- Авторизация: 3 позитивных и 5 негативных тестов на статус-код 200
- Динамическая подстановка токена в заголовки коллекции
- Получение текущего баланса → `current_balance`
- Получение тем публикаций → `subjects_name1..3`, `subjects_total`
- Получение документов ScanDoc по идентификаторам → `news_agent_1`, `news_agent_2`

## Файлы

- `collection.json` — коллекция Postman с запросами и тестами
- `test_data.csv` — тестовые логины и пароли

## Переменные коллекции

| Переменная | Назначение |
|---|---|
| `test_login` | логин из CSV |
| `test_password` | пароль из CSV |
| `current_balance` | текущий баланс пользователя |
| `subjects_name1..3` | названия первых трёх тем |
| `subjects_total` | общее число публикаций |
| `news_agent_1`, `news_agent_2` | названия новостных агентств |

## Запуск

1. Импортировать `collection.json` в Postman.
2. Подключить `test_data.csv` как источник данных (Runner → Data).
3. Запустить коллекцию через Collection Runner.
4. Проверить, что все тесты прошли со статус-кодом 200.

## Результаты

Коллекция и CSV-файл с тестовыми данными приложены в репозитории / по ссылке.
